# Regeln für Git
- Niemals direkt auf `main` committen oder pushen. Außer wenn man es dir ausdrücklich sagt.
- Für jede Aufgabe einen neuen Branch anlegen (z. B. `feature/...` oder `fix/...`). Vorher fragen auf welchen
- Änderungen auf diesen Branch pushen und einen Pull Request öffnen.
- Änderungen auf das Repo https://github.com/binkali/linasm-winasm-transpiler.git
